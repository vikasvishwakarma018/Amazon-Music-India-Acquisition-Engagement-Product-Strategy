# 🎵 Amazon Music India

## Acquisition & Engagement Strategy

### About This Project

This project explores how Amazon Music can grow its user base and improve user engagement in India. The focus is on understanding user needs, studying competitors, and creating practical strategies that help Amazon Music attract, engage, and retain more users.

---

## Problem Statement

Amazon Music faces strong competition from Spotify, YouTube Music, JioSaavn, and other music streaming platforms.

The goal of this project is to answer two key questions:

1. How can Amazon Music acquire more users in India?
2. How can Amazon Music keep users engaged and encourage long-term usage?
